Selected work

Products I’ve built end to end.

Shop Inventory Manager

A multi-tenant SaaS for retail shops — inventory, billing, credit book, daily closing, and reports. Live in production with paying users.

  • Multi-tenancy from the ground up: every shop’s data is isolated in Firestore subcollections, enforced by security rules — not just filtered in the UI.
  • Subscription lifecycle: signup → pending → admin activation → expiry & renewal, with an admin panel to manage every shop.
  • Built for real use: offline-friendly caching for speed, a daily-closing model that resets correctly per shop, and a menu tuned with an actual shopkeeper.
