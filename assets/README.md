# assets

Replace these with real files before publishing:

- **shop-app-1.svg** — placeholder mockup. Swap the `<img src>` in `index.html`
  to `assets/shop-app-1.png` and drop a real dashboard screenshot here
  (recommended ~1600×1000, cropped to the top of the screen).
  You can add more: `shop-app-2.png`, etc.
- **resume.pdf** — your CV. The hero "Download résumé" button links to
  `assets/resume.pdf`. Until you add it, that button 404s.

Tip for screenshots: use a **demo shop** (not a real shopkeeper's data),
zoom the browser to ~90%, and capture the dashboard, inventory, and a report.
